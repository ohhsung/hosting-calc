# 호스팅 등급변경 정산기

호스팅 요금제를 중간에 바꿀 때 **얼마를 받아야 하는지** 계산한다.

👉 https://ohhsung.github.io/hosting-calc/

## 왜 필요한가

`무제한 1,320,000 − 플러스 330,000 = 990,000` 이 값은 **계약 첫날** 가격이다.
9개월 쓴 고객한테 이 금액을 받고 1년을 주면, 이미 써버린 273일치 요금까지 깎아준 셈이 된다.

**차액은 남은 기간에만 붙는다. 이미 쓴 기간은 빼주는 게 아니다.**

## 두 가지 답

| | 받는 돈 | 만료일 |
|---|---|---|
| ① 만료일 그대로, 등급만 상향 | 남은 기간치 차액만 | 변동 없음 |
| ② 오늘부터 상위등급 1년 신규 | 정가 − 안 쓴 기간치 크레딧 | 오늘 + 1년 |

## 공식

```
Pc = 지금 등급 1년가      Pn = 바꿀 등급 1년가
T  = 365일               D  = 남은 일수      U = 365 − D
C  = Pc × D ÷ T          (안 쓴 크레딧)

①  (Pn − Pc) × D ÷ T
②  Pn − C
역산  D′ = (받을금액 + C) × T ÷ Pn

② = ① + Pn × U ÷ T         ← 남은 기간은 차액, 신규 기간은 정가
② − (Pn − Pc) = Pc × U ÷ T ← 전액 차감 시 손해액
```

## 가격표 수정

페이지 맨 위 가격표에서 상품명·가격·메모를 직접 고치면 계산이 즉시 반영된다.
상품 추가/삭제도 된다. 수정한 값은 **그 브라우저에만** 저장된다(localStorage).
초기값은 2026년 기준 가격이며 부가세 포함이다.
